    Readable in Ten Years: Static HTML and the Half-Life of Digital Work

    Most personal sites do not die from a lack of ideas — they die from a broken dependency tree. Crystallizing writing and craft as plain standard HTML is the surest hedge against link rot and tooling churn.

    § 01The Hidden Half-Life of Digital Publishing

    Lay out everything you have written and built over the past decade by storage medium, and a quiet law emerges: the thicker the abstraction stack, the shorter the half-life.01

    01 Static HTML pages published in 1996 open instantaneously today, while countless three-year-old JavaScript build pipelines already fail to install.
    Ten-year durability across personal publishing stacks
    Publishing Stack Typical Half-Life Primary Failure Mode
    Hosted SaaS Newsletter / Platform 2 – 5 yrs Business pivots, paywalls, link rot
    Database-Backed Dynamic CMS 3 – 6 yrs Hosting lapses, plugin security churn
    Heavy Frontend SSG Pipeline 2 – 4 yrs Dependency rot, breaking bundler upgrades
    Plain Sources + Standard HTML5 20+ yrs Evergreen browser compatibility, zero runtime

    § 02Zero Dependencies No Longer Means Low Craft

    Developers once tolerated heavy frontend stacks because the raw web platform lacked ergonomic primitives. By 2026, browsers ship native @layer cascade zones, light-dark(), native <dialog closedby="any">, and cross-document @view-transition. Standing directly on web standards delivers both longevity and contemporary polish.

    § 03Static Core, Modular Edge

    Inside Tong's Information, every essay, image plate, and machine manifest lives transparently inside Git and site/, while deploying on Cloudflare Workers Static Assets keeps an effortless door open for HTTP content negotiation and Remote MCP later. True longevity pairs an unbreakable static core with a modular doorway to the future.
