    让博客重新成为博客

    从初中的 Hexo、宝塔面板与 Sakurairo，到今天一页白纸般的原生 HTML 画布——当样式不再只是为了好看而好看的形式，博客终于可以顺着思潮呼吸、生长、演进。

    § 01旧器与少年心事

    从初中算起，我折腾个人博客已经有些年头了。

    最初是 Hexo 搭配 GitHub Pages01；后来买过不知名闲鱼小厂套壳阿里云轻量的虚拟主机——只能进宝塔面板，连流量都捉襟见肘02；再后来腾讯云 Lighthouse 问世，我终于拥有了自己的 VPS，在上面手搓 WordPress，不厌其烦地打磨各种主题（时至今日，我依然觉得我记忆里的 Sakurairo 美得惊艳）03。

    01 Hexo & GitHub Pages：基于 Node.js 的静态博客生成器搭配 GitHub 免费托管，写完 Markdown 敲一句 hexo g && hexo d 即可发布，是无数中文技术少年的第一座“数字自留地”。
    02 闲鱼套壳主机与宝塔面板：二手平台闲鱼上常见几块钱一年的廉价分销空间，通常把一台轻量云切成无数小隔间，仅开放可视化面板「宝塔（BT Panel）」，无完整 SSH 权限，月流量也极其紧张。
    03 Lighthouse 与 Sakurairo：腾讯云轻量应用服务器（入门独立 VPS）；Sakurairo 是中文 WordPress 圈极具代表性的开源二次元美学主题（衍生自 Mashiro 的 Sakura 主题），以精致的动态封面与细腻光影著称。

    甚至还因为没有成年，没法把博客托管在大陆 VPS 上，没办法使用阿里云 DCDN 来加速站点而郁闷。04

    04 未成年、ICP 备案与 DCDN：中国大陆境内的云服务器与全站加速 CDN（如阿里云 DCDN）依法要求域名完成 ICP 备案，而个人备案需年满 18 周岁——这道门槛曾让无数中学站长只能望低延迟节点兴叹。

    为不知将图片和视频托管在哪个图床上而焦虑。对象存储太过昂贵，我又想让根本没人访问的个人博客以最佳状态迎接它的第一个来访者。05

    05 图床与对象存储：早期个人站长常为云端对象存储（OSS/COS）和按量计费的下行流量犯愁，只好四处寻找免费第三方「图床」，在零成本与随时防盗链、跑路的风险间反复权衡。

    折腾许久，碍于升学等种种压力，博客闲置了。我的服务器也到期了。我没有选择续费。但如果现在让我去重复 7 年前我是怎么部署 WordPress 的，我肯定可以毫无阻碍地像当年一样熟练，乃至比当时更加关注许多细节。

    § 02放下框架这根拐杖

    随后大模型浪潮席卷而来，笨重的 CMS 逐渐显得多余，甚至称得上束缚。我换上了 Astro 与 VuePress 这样轻盈的框架，将文字放在 Cloudflare Workers 的边缘节点之上。06

    06 Astro、VuePress 与边缘节点：以内容为中心的轻量化现代静态站点框架，结合 Cloudflare 遍布全球的边缘网络部署，彻底摆脱了维护单台 VPS、续费与升级数据库的包袱。

    而走到今天，我们似乎连“框架”这根拐杖也可以放下了。AI 让想法与呈现之间的距离归零，浏览器彻底化作了创作者手中的画布：仅凭一个单页 HTML，便有人搭起瑰丽的 3D 世界，有人演绎动态的科普视界，甚至塞进了一整部 3D 射击游戏。

    若是退回三年前，冒出这种念头的我，大概会怀疑自己是不是吃错了菌子。07

    07 吃错了菌子：中国西南地区（尤以云南及川渝语境亲切常见）的幽默俗语——误食未熟野生毒菌易见幻象，这里戏称“怀疑自己是不是产生了幻觉”。

    可如今，左手是 Gemini 4 Neon 灵动的想象力，右手是 GPT 6.2 Astra 缜密的执行力，一页白纸般的 HTML，终于可以长成我脑海中的任何模样。

    物非人是啊。08

    08 物非人是：化用成语「物是人非」的反写——服务器、面板、主题与框架早已面目全非，但屏幕背后那个爱折腾、对世界保持好奇的人，依然还是当年的少年。

    § 03从物质走向精神

    感慨之外，更多的是兴奋。我的博客终于不必再困于千篇一律的 CSDN 样式（以及在各大主题群里流传的祖传 CSS 样式）09，它现在可以顺着我的思潮呼吸、生长、演进。

    09 CSDN 样式与主题群“祖传 CSS”：CSDN 是中文互联网年代悠久的开发者社区，版式高度千篇一律；而在独立博客主题交流群里，大家常相互拷贝流传多年的同一套魔改 CSS 片段，久而久之全网博客又渐渐长得越来越像。

    样式不再是为了好看而好看的形式，而是变成了个人独特审美的传递。从关心物质本身，到关心人的精神本身跃进了一大步。

    § 04开源、见证与新玩具

    于是我将这里的每一行代码全部开源。也许十年后，“独立博客”早已成为互联网的遗迹，我对自我表达也会生出新的理解；但至少，这间仓库的 Commit 记录会保存：在这个时代，LLM 曾如何改变我的生活、思维和创造方式。

    某种历史的见证吗？

    我大概只是个刚得到新玩具的孩子，满心欢喜地拆开、把玩，急不可待地想把脑子里的好点子捧给全世界看。
