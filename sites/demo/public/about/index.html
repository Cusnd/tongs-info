    关于 Tong's Information - Demo

    一份完全跳出传统静态博客框架、由作者与 AI Agent 协同编排的双语个人数字刊物。全静态 HTML5、零构建链、托管于 Cloudflare Workers Static Assets。

    • § 01 出版理念
    • § 02 编辑部工作流
    • § 03 机器可读接口

    § 01出版理念

    Tong's Information - Demo 是 Tong's Information 的公开演示站点，拒绝将每篇思考强行塞进同一套博客模板。普通随笔（Essay）追求克制的瑞士排印与右侧边注节奏；重点专题（Feature）则允许 Agent 依据主题直接内嵌零依赖的交互实验装置。

    全站默认实行中英双语出版：只需在灵感最自然的那种语言中写下原稿，Agent 编辑部负责地道本地化、排印节奏微调以及双语互链。

    § 02编辑部工作流

    1. 纯文本沉淀：所有原始思想保存在 sources/ 目录，确保内容与呈现长期解耦。
    2. Agent 编排 HTML：依据 editorial/DESIGN.md 与 AGENTS.md 产出语义清晰的静态 HTML5。
    3. 确定性脚本护航：零依赖的 tools/editorial_sync.py 统一同步页眉页脚、派生 index.md 孪生原稿、生成机器协议文件并执行全站死链体检。
    4. 边缘演进跑道：通过 cf deploy ./site 部署至 Cloudflare Workers Static Assets，随时可按需叠加 Accept: text/markdown 内容协商与 Remote MCP 能力。

    § 03机器可读接口清单

    面向外部 AI Agent 与订阅器的公开端点
    端点路径 格式 用途
    /llms.txt text/plain 全站 Agent 发现索引与双语文章入口
    /llms-full.txt text/plain 全站洁净文本合集，适合一次性注入长上下文
    /api/posts.json application/json 全部文章元数据、分级与 index.md 路径
    /api/graph.json application/json 文章与概念双向拓扑图谱数据
    /api/stream.json application/json 双语思维碎片与关联概念数据
    /stream/rss.xml · /en/stream/rss.xml application/rss+xml 思维页独立双语 RSS 2.0 订阅源（与长文主源分离）
    /rss.xml · /en/rss.xml application/rss+xml 中英双语独立 RSS 2.0 订阅源
