    双面万维网：同时写给人类眼睛与 AI Agent 的出版架构

    当互联网一半以上的读者不再拥有视网膜，个人网站应该如何在不牺牲一丝人类审美的前提下，成为一台高信噪比的机器可读信息仪器？

    § 01两种截然不同的“阅读器官”

    二十世纪的平面设计师只需要面对一种读者：拥有视网膜、注意力有限、通过版面秩序和视觉留白建立理解的人类。瑞士现代主义（International Typographic Style）正是为此而生——用数学网格、极细分割线与清晰的字号层级，让信息在扫视的一瞬间显露骨架。01

    01 约瑟夫·穆勒-布罗克曼在《平面设计中的网格系统》中强调：秩序不是束缚，而是让复杂信息被快速解码的脚手架。

    但从 2025 年之后，任何公开发布在互联网上的文章，几乎同时都在迎接第二类读者：AI Agent、检索代理与个人知识助理。它们的“阅读器官”优化的目标截然不同：

    • 人类需要：排印呼吸感、边注与图表、暗色护眼配色、甚至可以动手拖拽参数的交互实验。
    • Agent 需要：极高的语义信噪比、极低的 Token 噪声、显式的目录索引、稳定的规范 URL、以及清晰的概念拓扑关系。

    § 02一文双面：Human Edition × Agent Edition

    Tong's Information 采用的解法叫做 Dual-Surface Static Publishing（双面静态出版）。每一篇文章在同一个 URL 目录下同时拥有两张面孔：由 Agent 编排的杂志版 index.html，以及零噪音的洁净 index.md，并在文档头部通过 <link rel="alternate" type="text/markdown" href="./index.md"> 显式宣告机器可读孪生体。

    § 03为什么选 Cloudflare Workers Static Assets

    既然当下的核心产物是 100% 纯静态的 site/ 目录，为什么不随便找个静态托管，而特意选在 Cloudflare Workers Static Assets 上？因为它是面向未来演进阻力最小的一条跑道。02

    02 使用官方 cf deploy ./site 即可跳过任何构建工具，将纯静态文件部署为 assets-only Worker，零冷启动、支持自定义 _headers 与 404.html。
    1. HTTP 内容协商（Content Negotiation）：未来只需挂一个几十行 Worker 脚本，当外部 Agent 请求带 Accept: text/markdown 时边缘直接返回 index.md，人类浏览器则照常收到完整杂志版。
    2. 个人博客 Remote MCP Server：基于 Cloudflare Agents SDK 暴露只读工具（search_essays、read_issue、explore_graph），让任何支持 MCP 的 AI 客户端直接把你的个人思想库挂载为外脑。
    3. 边缘语义检索：按需接入 Cloudflare AI Search，在不破坏纯静态阅读核心的前提下提供基于全站内容的语义检索与问答。

    § 04结语：静态不是守旧，而是最稳固的发射台

    许多人误以为“全静态 HTML”是一种复古怀旧。恰恰相反：在技术栈半年一迭代的今天，把内容、排印与机器协议沉淀为透明、无框架、可版本控制的静态文件，同时把边缘计算作为按需挂载的可选能力，才是个人数字领地最具前瞻性的架构选择。
