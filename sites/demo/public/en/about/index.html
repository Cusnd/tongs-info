    About Tong's Information - Demo

    An independent, fully static bilingual publication co-produced by its author and an AI agent editorial desk. Zero frameworks, deployed on Cloudflare Workers Static Assets.

    • § 01 Editorial Thesis
    • § 02 Desk Workflow

    § 01Editorial Thesis

    Tong's Information - Demo is the live open-source showcase of Tong's Information, rejecting forcing every idea into the same monotonous blog template. Standard pieces (Essays) follow quiet Swiss print typography with margin sidenotes; flagship investigations (Features) embed zero-dependency interactive laboratories directly inside static HTML.

    Bilingual publication is built into the core: drafts begin in whichever language fits the thought, and the agent editorial desk produces idiomatic Chinese and English editions with language-tuned typography and symmetric links.

    § 02Desk Workflow

    1. Plain-Text Truth: Every manuscript starts in sources/, keeping raw ideas decoupled from layout forever.
    2. Agent-Crafted HTML: Guided by editorial/DESIGN.md and AGENTS.md, the agent authors semantic HTML5 directly inside site/.
    3. Deterministic Guardrails: A zero-dependency Python script (tools/editorial_sync.py) syncs shared chrome, emits clean Markdown twins and discovery manifests, and validates links and metadata.
    4. Edge Evolution: Deployed via cf deploy ./site to Cloudflare Workers Static Assets — zero runtime today, ready for HTTP content negotiation and Remote MCP tomorrow.
